# About
A gentle and childhood-inspired terminal color theme. The theme is inspired by the ["Kikker"](https://en.wikipedia.org/wiki/Frog_(picture_book_character)) (English: Frog) children book series written and designed by the late [Max Velthuijs](https://en.wikipedia.org/wiki/Max_Velthuijs).
